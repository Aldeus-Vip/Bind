# 3D モデルの作り方と差し替え手順

## 1. 仕組み(実装済み)

- `assets/models/manifest.json` に書いた生物だけ、`.glb` モデルに置き換わる。
- 足元の陣・スートのオーラ・頭上カード・召喚・演出は今までどおり(器と見た目の分離のおかげ)。
- モデルの大きさは `height` に合わせて自動で縮尺。足元が原点になるよう自動で位置合わせ。
- 質感は既定でトゥーン調に変換(`"toon": false` で元の PBR のまま)。

| モデル側の決まり | 効果 |
|---|---|
| メッシュ名に `eye` を含む | まばたきする |
| メッシュ名に `glow` を含む(発光あり) | スートの色で光る |
| ボーン/ノード名 `Head` | 頭として扱う |
| アニメーション `Idle` / `Attack` / `Jump` | 待機 / 術を構える / 跳躍 に自動で切り替え(名前は manifest の `anims` で変更可) |

### リグはあるがアニメーションが無いとき

Meshy の四足獣リグなど、アニメーションが付かないモデルは、manifest の `rig` に骨の名前を書くと、
コードで骨を動かします(呼吸・首振り・尻尾・耳・術を構えるときの咆哮・跳躍の溜め)。
例は `assets/models/manifest.json` の `beast-A`。骨の名前は Blender か、私(Claude)に .glb を渡して調べられます。

| rig の項目 | 意味 |
|---|---|
| `spine` | 背骨(腰→胸の順) |
| `neck` | 首(根元→先) |
| `head` / `jaw` | 頭 / 下あご |
| `tail` | 尻尾(根元→先) |
| `ears` | 耳(左右) |

キー: `beast-A`(A)、`c2`〜`c13`(2〜K)、`jb`(黒JOKER)、`jw`(白JOKER)

### 軽量化(ビルド時に自動)

- `npm run build` のとき、`tools/optimize_models.mjs` がテクスチャを最大 1024px に縮小して `dist/web/models/` に出す。
- 元の `.glb`(`assets/models/`)は変更しない。高解像度の元データとして残る。
- 1体だけ大きくしたいときは manifest に `"textureSize": 2048` などと書く。
- 例: beast-A.glb 10.4MB → 1.7MB(見た目はほぼ同じ)。

## 2. モデルの入手方法(比較)

| 方法 | 品質 | 手間 | 費用 | 向いている用途 |
|---|---|---|---|---|
| A. 画像→3D の生成AI(Meshy / Tripo / Rodin など)にコンセプトアートを入れる | 中〜高(要修正) | 小 | 月額〜数千円 | まず15体を揃える |
| B. A の結果を Blender で修正 + 自動リグ(Mixamo / AccuRIG) | 高 | 中 | ほぼ無料 | 本番品質へ仕上げ |
| C. 3D モデラーに外注 | 最高 | 小(依頼のみ) | 1体 数万円〜 | 最終版・商用 |
| D. Blender で手作り | 高 | 大 | 無料 | こだわりの1体 |

おすすめの順番: **A で全体を揃える → 目立つ生物(A・8・K・JOKER)から B で仕上げる**。

## 3. 生成AI(A)の手順

1. `assets/concept_art/<数字>.jpg` を画像→3D 生成に入れる(背景は消しておくと精度が上がる)。
2. 書き出し形式は **glTF バイナリ(.glb)**、ポリゴンは 1体 1〜3万三角形、テクスチャ 1024px 程度。
3. 動かしたいものはリグ付け(Mixamo 等)して `Idle` `Attack` `Jump` を付ける。
4. `assets/models/` に置き、`manifest.json` に1行追加。
5. `npm run build && npm run serve` → ブラウザで確認。`npm run test:models` でも読み込み経路を確認できる。

## 4. 品質の目安

- 真上寄りのカメラで小さく映るので、**シルエットと配色**が最優先(細部より輪郭)。
- 1体あたり .glb 2MB 以下を目安(15体 × 2体分ロードしても軽く)。
- 正面が +Z(カメラ側)。違う場合は `rotY` で補正。
