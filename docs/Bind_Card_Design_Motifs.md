# Bind --- カードデザイン・モチーフ設定資料

## 1. 基本コンセプト

**Bind** は、トランプを使った2人用の戦略ゲーム。

カードは単なる数字・スートではなく、Bindの世界に存在する**生物・力・術式**を表現する。

カードデザインでは、

-   **Number（数字）＝能力・個体が持つ固有能力**
-   **Suit（スート）＝属性・術式の系統**
-   **カードそのもの＝Bind世界に存在する生物／存在**
-   **フロア＝大地・封印された世界**
-   **裏向きのフロア＝封印された状態**
-   **表向きのフロア＝解放された状態**

という関係性を基本とする。

ゲーム中の効果とカードアートが一致することで、「数字とスートを組み合わせて力を行使する」という世界観を作る。

------------------------------------------------------------------------

# 2. Bindの世界観

Bindという名称には、

-   拘束
-   束縛
-   封じる
-   封印

といった意味を持たせる。

世界観としては、

> **大地に封じ込められた生物たちの力を呼び起こし、大地を踏みしめながら戦う**

というイメージ。

カードは封印された生物やその力を象徴し、ゲーム中にカードを操作すること自体が、封印・解放・破壊・創造・知識の奪取などの行為になる。

------------------------------------------------------------------------

# 3. スートの四大術式

4スートは単なる属性ではなく、それぞれ異なる「術」の体系を表す。

  ----------------------------------------------------------------------------------------------------
  Suit           術式           ゲーム上の効果                     基本イメージ         メインカラー
  -------------- -------------- ---------------------------------- -------------------- --------------
  ♥ Heart        **魔術**       裏向きのフロアを表向きにする       封印の解放           深紅・紅

  ♠ Spade        **呪術**       相手の手札を奪う                   知識の奪取・支配     紫・紫紺

  ♦ Diamond      **錬金術**     捨て札を利用してフロアを生成する   創造・錬成           金・橙

  ♣ Club         **占星術**     捨て札を利用してカードを引く       知識の増殖・未来視   紺・青・金
  ----------------------------------------------------------------------------------------------------

## ♥ Heart --- 封印を解放する魔術

### 概念

**「閉ざされたものを開き、眠っている力を解放する」**

裏向きのフロアを表向きにする効果から、封印解除・解放の魔術として表現する。

### ビジュアル

-   深い紅色
-   紅い魔力
-   封印陣
-   砕ける鎖
-   光の裂け目
-   炎のような魔力
-   閉じられていた力が外へ流れ出す表現

明るい赤ではなく、**深紅〜紅**を基調とする。

破壊ではなく「封印を解く」力なので、闇よりも神聖・生命的な方向に寄せる。

------------------------------------------------------------------------

## ♠ Spade --- 知識を奪う呪術

### 概念

**「他者から知識・記憶・力を奪い、自らのものとする」**

相手の手札を捨てさせる効果から、知識を奪う呪術として表現する。

### ビジュアル

-   黒〜紫ではなく、**紫・紫紺を主体**
-   黒曜石
-   黒曜石の刃
-   封印の楔
-   呪いの目
-   紫色の妖しい光
-   闇の魔力
-   呪術的な紋様

特にスペードマーク自体は、

> **スペード上部の尖った部分＝黒曜石の刃**
>
> **スペード内部＝封印の楔**
>
> **楔の中心＝呪いの目玉**

というデザイン思想。

「真っ黒なカード」ではなく、**黒を土台に紫の怪しい発光を使う**ことで、呪われた存在感を出す。

------------------------------------------------------------------------

## ♦ Diamond --- 物質を創造する錬金術

### 概念

**「無から有を生み、物質を変換し、新たな形を錬成する」**

捨て札を山札へ戻し、その結果として新しいフロアを生み出す効果から、錬金術として表現する。

### ビジュアル

-   黄金
-   橙
-   土
-   鉱物
-   金属
-   錬金陣
-   黄金の粒子
-   黄金のダイヤ形結晶

錬金術は土・鉱物との親和性が高いため、**大地＋黄金**を基本モチーフとする。

Aカードでは、黄金の粒子だけでは視認性が弱かったため、

> **聖獣の周囲に黄金のダイヤ形結晶を浮かべ、背後からの光を乱反射させてキラキラと輝かせる**

という表現を採用する。

------------------------------------------------------------------------

## ♣ Club --- 星を読む占星術

### 概念

**「星の運行から知識を得て、未来を読み、可能性を広げる」**

捨て札を山札へ戻すことでカードを引く効果から、知識の増殖・未来視を司る占星術として表現する。

### ビジュアル

-   夜空を思わせる紺
-   青い光
-   金色の星
-   星座
-   星の軌跡
-   タロット／占術を思わせる図形
-   魔法陣
-   未来を感じさせる光

「夜＝暗い」という方向には寄せすぎず、

> **夜空でありながら、未来を感じさせる明るさ**

を重視する。

Aカードでは、聖獣の白銀の体躯を軽く発光させ、星々と星座の光を周囲に配置することで、希望的・神秘的な雰囲気を出す。

------------------------------------------------------------------------

# 4. Aカード --- 封印の聖獣

## 共通コンセプト

Aは特別なカードなので、4スートすべてで同一系統の存在を描く。

名称：

**「封印の聖獣」**

コンセプト：

> **すべての封印を司る守護獣。**

Bind世界において、フロア（大地）を裏返し、新たな舞台を創造する存在。

死と再生、沈黙と光を内包する「境界の聖獣」。

------------------------------------------------------------------------

## 共通ビジュアル

-   白銀〜灰色を基調とした神聖な体躯
-   獅子・狼・龍を融合したようなシルエット
-   身体に封印紋様
-   身体に巻き付く鎖
-   胸部中央に光の核（コア）
-   足元に封印陣
-   大地のひび割れ
-   大地から漏れる光
-   中央に堂々と座する構図
-   前脚で大地を押さえ、封印を維持する姿

4枚とも**同一の聖獣を別属性として表現する**ことが重要。

------------------------------------------------------------------------

## ♥ A --- 解放の聖獣

**テーマ：封印の解放・魂の昇華**

胸のコアが紅く発光 - 炎のような毛並み

雰囲気：

**神聖・力強い・生命・解放**

ことで、単なる「紫色の聖獣」ではなく、明確に呪われた存在として表現する。

# 5. JOKER

## 基本コンセプト

JOKERは通常のスート体系から外れた**切り札・異端の存在**。

ゲーム上でも、

-   フロアを最大2枚処理できる
-   相手の手札を処理できる
-   相手の捨て札を操作する
-   山札トップを操作する

など、盤面・手札・山札というBindの重要要素を横断して干渉する。

そのため、通常のスートとは異なる特別な存在としてデザインする。

------------------------------------------------------------------------

## 黒JOKER --- Reaper of Collapse

モチーフ：

**死神／破壊／崩壊**

ビジュアル：

-   黒いローブ
-   骨の顔
-   闇
-   崩壊する大地
-   赤黒い亀裂
-   呪われた鎌・死神的シルエット
-   カード全体を侵食する暗闇

黒JOKERのキャッチコピー：

> **All order returns to ruin in the end.**

デザイン上は黒を主体とし、赤い亀裂・光をアクセントにする。

------------------------------------------------------------------------

## 白JOKER

黒JOKERと対になる存在。

モチーフ：

**再生／精霊／秩序の再構築**

黒JOKERが「破壊」であるのに対し、白JOKERは「再生」を象徴する。

黒と白のJOKERを並べることで、

**破壊と再生**

**終焉と始まり**

というBind世界の対立軸を作る。

------------------------------------------------------------------------

# 6. カード裏面

フロアとして使用するカードの裏面は、ゲームシステム上かなり重要。

Bindでは、裏向きのカードは**誰のものでもない大地／封印されたフロア**として扱う。

したがって裏面には以下が必要。

## 点対称

トランプとして、

> **裏向きである限り、カードの向きから所有者や情報が判別できない**

ことが重要。

上下を反転しても同じデザインになる、**180度点対称**の構造を基本とする。

------------------------------------------------------------------------

## デザインコンセプト

裏面は、

**「封印された大地」**

を表現する。

要素：

-   大地
-   石
-   ひび割れ
-   封印
-   地面の中央部
-   周囲が自然に浮き上がって見える構造
-   中央に少し窪んだ領域
-   周囲に浮き上がった地面
-   Bindロゴ

中央を少し窪ませることで、カードの周囲が自然に浮き上がって見える。

その浮き上がった部分にBindロゴを配置することで、

> **大地からロゴが浮かび上がっている**

ように見せる。

------------------------------------------------------------------------

## Bindロゴ

Bindのロゴ自体はシンプルにする。

コンセプト：

-   大地を連想させる文字
-   文字に鎖が巻き付く
-   鎖が文字を封印している
-   しかし封印が解放されかかっている
-   大地に亀裂
-   亀裂の内部から光

「拘束」「封印」「解放」というBindの意味を一つのロゴにまとめる。

裏面ではロゴを主役にしすぎず、

**大地の中に自然に存在している紋章**

として扱う。

------------------------------------------------------------------------

# 7. カードフレーム

Aカードで確立したフレームを基本テンプレートとする。

## 基本構造

-   生成紙／古いカードを思わせる淡い外周
-   内側に細いスートカラーのライン
-   左上にランク
-   左上にスートマーク
-   右下に上下反転したランク

トランプとしての視認性を保ちながら、Bind専用カードとしての質感を与える。

# 8. Effect UI

カード下部に、

1.  **NUMBER EFFECT**
2.  **SUIT EFFECT**

の2つの効果欄を配置する。

ゲーム中に、

> 「これはNumberの能力なのか、Suitの術式なのか」

を即座に判別できることが目的。

## 基本方針

効果欄自体は**シンプルで実用的**にする。

カードアートが世界観を担い、効果欄はUIとして情報を正確に伝える。

------------------------------------------------------------------------

## NUMBER EFFECT

数字はカードの固有能力を表すため、

**能力・封印文字・ルーン**

を連想させる。

ラベルは装飾しすぎず、視認性を優先する。

現在のカードデザインでは、

**MonoType Corsiva**

のような筆記・魔術的な書体も候補。

------------------------------------------------------------------------

## SUIT EFFECT

スートは4つの術式を表す。

-   S → 魔術（Heart）
-   U → 呪術（Spade）
-   I → 錬金術（Diamond）
-   T → 占星術（Club）

という文字そのものへの象徴要素を混ぜる案がある。

NUMBER EFFECTとは明確に異なるデザインとし、

**「能力」対「術式」**

が視覚的に分かるようにする。

------------------------------------------------------------------------

# 9. デザイン原則

Bindのカードデザインでは、以下を共通原則とする。

### ① ゲーム効果をアートに反映する

数字・スートの効果を単なる説明として扱わず、カードの存在理由としてビジュアル化する。

### ② 同じ数字は同じ存在系統

特にAのような重要カードは、4スートで同一モチーフを使い、属性だけを変える。

### ③ スートは色だけでなく「術」を変える

単純な色違いではなく、

-   Heart → 魔術
-   Spade → 呪術
-   Diamond → 錬金術
-   Club → 占星術

として、エフェクト・背景・光・装飾まで変化させる。

### ④ UIとアートを分離する

カードアートは世界観を重視。

効果テキストは読みやすさを最優先。

### ⑤ トランプとしての機能性を維持する

裏面は点対称。

ランクとスートは上下どちらからでも確認可能。

ゲーム中の情報量が多いため、装飾によって重要情報が埋もれないようにする。

------------------------------------------------------------------------

# 10. 今後のカード制作方針

各数字について「その数字の能力を象徴する生物・存在」を設定し、その存在を4スートで属性変化させる。

基本構造：

> **共通モチーフ（Number）**
>
> ＋
>
> **スート固有の術式・属性**
>
> ＝
>
> **Bindのカード**

例えばAなら「封印の聖獣」が共通モチーフ。

そこに、

-   Heartの解放魔術
-   Spadeの呪術
-   Diamondの錬金術
-   Clubの占星術

を掛け合わせる。

これにより、カードを見ただけでも

**「これは何のカードなのか」**

**「どのような力を持つのか」**

**「どの術式に属するのか」**

が世界観として理解できることを目標とする。

# 11. Bindのビジュアルキーワード

全体を通して以下の言葉をデザイン指針とする。

**大地 / 封印 / 解放 / 鎖 / 亀裂 / 光 / 生物 / 神話 / 魔術 / 呪術 /
錬金術 / 占星術 / 知識 / 破壊 / 再生 / 運命 / 創造 / 拘束 / 解放**

最終的には、

> **「封印された大地に眠る生物たちの力を、四つの術式によって呼び起こして戦うトランプゲーム」**

という一文に集約できるビジュアル体系を目指す。
